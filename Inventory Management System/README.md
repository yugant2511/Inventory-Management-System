# Inventory Management System (Java)

## Overview
This is a console-based Inventory Management System developed in Java.  
It demonstrates the use of core Java concepts such as Collections Framework, OOP principles, sorting, searching, and undo functionality.

## Features
- Add and manage products using unique SKU
- Prevent duplicate products using HashSet
- Display products in sorted order (SKU, Name, Price, Inventory Value)
- Track inventory updates using transaction history
- Undo last quantity update using Stack
- Identify low stock products using Queue
- Generate inventory statistics and category-wise breakdown

## Technologies Used
- Java
- Java Collections Framework
- OOP (Encapsulation, Abstraction)
- Comparable and Comparator
- Generics

## Data Structures Used
- HashSet for unique product storage
- TreeSet for natural sorting
- LinkedList for transaction history
- Stack for undo operations
- Queue for low stock alerts
